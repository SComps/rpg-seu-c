# RPG2C Transpiler Usage Guide

## Overview

The RPG2C transpiler converts RPG II source code to C code that uses the RPG Runtime Library. This guide explains how to use the transpiler and compile the generated code.

## Prerequisites

- .NET 10.0 SDK
- GCC or Clang compiler
- SQLite development libraries (`libsqlite3-dev`)
- RPG Runtime Library (included in this project)

## Building the Transpiler

```bash
cd /home/scott/rpg-seu-c/RPG2C
dotnet build
```

The transpiler executable will be created at:
`bin/Debug/net10.0/RPG2C`

## Using the Transpiler

### Basic Usage

```bash
./bin/Debug/net10.0/RPG2C <input.rpg>
```

This will:
1. Parse the RPG source file
2. Generate a listing file (`.lst`)
3. Generate C source code (`.c`)

### Example

```bash
cd /home/scott/rpg-seu-c/RPG2C
./bin/Debug/net10.0/RPG2C test.rpg
```

Output files:
- `test.lst` - Listing file with line numbers and any errors
- `test.c` - Generated C source code

## Compiling Generated Code

The generated C code requires the RPG Runtime Library. You have two options:

### Option 1: Link with Static Library

```bash
gcc -o myprogram test.c \
    -I/home/scott/rpg-seu-c/Runtime \
    -L/home/scott/rpg-seu-c/Runtime/build \
    -lrpg_runtime -lm -lsqlite3
```

### Option 2: Link with Shared Library

```bash
gcc -o myprogram test.c \
    -I/home/scott/rpg-seu-c/Runtime \
    -L/home/scott/rpg-seu-c/Runtime/build \
    -lrpg_runtime -lm -lsqlite3

# Set library path for runtime
export LD_LIBRARY_PATH=/home/scott/rpg-seu-c/Runtime/build:$LD_LIBRARY_PATH
./myprogram
```

## Generated Code Structure

The transpiler generates C code with the following structure:

```c
/*
 * Generated by RPG2C Transpiler
 * Using RPG Runtime Library v1.0
 */

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>
#include "rpg_runtime.h"
#include "rpg_file.h"
#include "rpg_data.h"

// Indicators
bool IND[100] = {false};
bool IN_LR = false;
// ... other indicators

// Program Variables
double NUM1 = 0.0;
// ... other variables

int main(int argc, char** argv) {
    // Initialize RPG runtime
    rpg_init();
    
    // ... program logic
    
    // Cleanup RPG runtime
    rpg_cleanup();
    return 0;
}
```

## Runtime Library Features

The generated code uses the following runtime library components:

### Core Runtime (rpg_runtime.h)
- Packed decimal encode/decode
- Zoned decimal encode/decode
- String operations (CAT, SUBST, SCAN, XLATE, TRIM)
- Array operations (LOOKUP, XFOOT, SORTA)
- Indicator management
- Date/time operations
- Error handling

### File Operations (rpg_file.h)
- Sequential file I/O
- Relative file I/O (direct access)
- Indexed file I/O (SQLite-based)
- CHAIN, SETLL, SETGT operations
- UPDATE, DELETE operations

### Data Structures (rpg_data.h)
- Data structure definitions
- Nested structures
- Qualified names
- Array operations
- Binary field support

## Troubleshooting

### "rpg_runtime.h: No such file or directory"

Make sure to include the Runtime directory in your include path:
```bash
-I/home/scott/rpg-seu-c/Runtime
```

### "undefined reference to rpg_init"

Make sure to link with the runtime library:
```bash
-L/home/scott/rpg-seu-c/Runtime/build -lrpg_runtime
```

### "error while loading shared libraries: librpg_runtime.so"

Set the library path:
```bash
export LD_LIBRARY_PATH=/home/scott/rpg-seu-c/Runtime/build:$LD_LIBRARY_PATH
```

Or use the static library instead (`.a` file).

### SQLite Errors

Make sure SQLite development libraries are installed:
```bash
sudo apt-get install libsqlite3-dev  # Debian/Ubuntu
sudo yum install sqlite-devel        # RHEL/CentOS
```

## Makefile Template

Create a `Makefile` for your RPG programs:

```makefile
CC = gcc
CFLAGS = -Wall -O2 -I/home/scott/rpg-seu-c/Runtime
LDFLAGS = -L/home/scott/rpg-seu-c/Runtime/build
LIBS = -lrpg_runtime -lm -lsqlite3

TRANSPILER = /home/scott/rpg-seu-c/RPG2C/bin/Debug/net10.0/RPG2C

%.c: %.rpg
	$(TRANSPILER) $<

%: %.c
	$(CC) $(CFLAGS) -o $@ $< $(LDFLAGS) $(LIBS)

clean:
	rm -f *.c *.lst *.o

.PHONY: clean
```

Usage:
```bash
make myprogram    # Transpiles myprogram.rpg and compiles to executable
```
